Privacy Policy

Last updated: June 8, 2026

Overview

YT CC Copy is a browser extension that helps you copy YouTube closed captions and save per-video notes. We built it with privacy as a default — the extension collects no personal data and makes no network requests of its own.

Data Stored Locally

When you use the "Save to Note" feature, caption text is stored using browser.storage.local — a storage area that exists entirely on your own device. Notes are keyed by YouTube video ID and never transmitted to any server, third party, or developer.

You can remove saved note data at any time using the Clear action inside the extension popup. Uninstalling the extension removes all locally stored data.

Permissions Used

storage

Used exclusively to save and retrieve per-video caption notes on your local device. No data leaves your browser.

tabs

Used to detect which YouTube tab is currently active so the extension can read captions from the correct page. No tab history or browsing data is collected or stored.

No Analytics or Tracking

YT CC Copy contains no analytics, telemetry, crash reporting, or advertising code. There are no third-party scripts bundled with the extension. Your usage patterns, browsing history, and clipboard contents are never observed or recorded by us.

Changes to This Policy

If this privacy policy changes, the updated version will be published in the GitHub repository alongside the relevant release notes. The "Last updated" date at the top of this page will reflect the most recent revision.
