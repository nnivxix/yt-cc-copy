Features

Copy CC Instantly

Grab currently visible closed captions from YouTube without leaving the video.

Save to Note

Append captured captions to a note tied to the active video for organized research.

Copy Full Note

Pull your whole saved note to clipboard when you are ready to share or archive it.

Simple Controls

Clean popup actions for copy, save, clear, and note management with clear status feedback.

FAQ

Which browsers are supported?

The extension is available on Chrome and Firefox through their official extension stores.

How do I copy captions?

Open a YouTube video with captions enabled, click the extension, then use Copy CC.

How do notes work?

Use Save to Note to append captions for the active video, then use Copy Note to export everything.

Can I clear saved notes?

Yes. The popup includes a Clear action to remove saved note content for the current video.
